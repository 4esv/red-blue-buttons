# data

## `empirics_grid.json`

41×41 sweep over (altruism, trust). Each cell is the average of 80 simulated populations of 3,000 agents. Generated by `scripts/generate_empirics_grid.py`.

Schema:

```jsonc
{
  "grid_size": 41,
  "altruism_axis": [..],         // 41 values, 0.05..0.95
  "trust_axis":    [..],         // 41 values, 0.05..0.95
  "p_blue_wins_grid": [[..]],    // 41x41
  "survival_grid":    [[..]],    // 41x41
  "cells": [{a, p, p_blue_wins, survival, blue_fraction}, ...],
  "indifference_curve": [{a, p}],   // p = 1/(1+a) sampled for the overlay
  "params_held_fixed": {n_agents, n_runs_per_cell, error_rate, ...}
}
```

The `p_blue_wins_grid` and `survival_grid` are arranged `[i_altruism][j_trust]` to match the axes. The flat `cells` array is the same data, flattened, easier to index from JS for hover affordances.

## `countries.json`

Curated WVS Wave 7 trust values for ~22 countries, paired with the global dictator-game altruism average (a = 0.28) for everyone. The metadata block documents sources and caveats.

These numbers are approximate. Treat them as illustrative; verify against the WVS release before citing in anything load-bearing. The qualitative claims in the article (Scandinavia clusters in the trap zone, low-trust countries are safer) are robust to ±5 percentage points on any one country.
