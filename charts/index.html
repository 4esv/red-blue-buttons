charts

Standalone interactive figures for the article. Each one is a single HTML file plus the shared CSS / JS in this folder. They expect to be served (the heatmap fetches data/empirics_grid.json); see the repo README for the one-line server command.

chart_logic

The threshold

Two threshold curves on (a, p). Slider for your altruism. Tells you what trust each decision rule needs you to have.

chart_empirics

Where countries land

Side-by-side P(blue wins) and survival heatmaps. Drag a marker, toggle the country layer, see the trap zone.

chart_trap_zone

The trap zone

Survival heatmap on the (a, p) plane with both threshold curves and a draggable crosshair.

chart_universal

Universal blue vs universal red

Two-bar body-count comparison at a 5% misclick rate. The moral case for blue, made visible.
